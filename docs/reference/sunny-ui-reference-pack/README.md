## What this is

- **`Character_References/`** — Sunny's visual character identity: the
  default look plus costume/accessory variants (sunglasses, goggles and
  pashmina, monocle, cowboy), a photo of the physical plush, and a
  movement reference sheet.
- **`Touchscreen_Mockups/`** — captures of the boot and home screens as
  they appeared on 2026-08-09.

## Status — read before relying on these

These are **design reference images, not production assets and not a
source of truth**.

- The mockups are a **2026-08-09 snapshot**. The UI has changed since;
  they do not necessarily match the current screens.
- The character references are look-and-feel material. The assets that
  actually build Sunny's animations are the committed frame sets under
  `src/assets/sunny/`.
- Origin and licensing of these images are **not recorded**. Confirm
  before any public or commercial use.

The source ZIP has been left in place in `~/Downloads`; it was not deleted.
